# We've moved!

Primer ViewComponents (PVC) are in [maintenance mode](https://github.com/primer/view_components/discussions/3908), and managed via a separate gem: https://github.com/primer/view_components.

[React is a paved path](https://thehub.github.com/epd/engineering/dev-practicals/frontend/react/adoption-guidelines/) at GitHub. We recommend using [Primer React](https://primer.style/product/getting-started/react/) for all new GitHub web UIs.
