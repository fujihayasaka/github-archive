# Repository pickers

Set of components that let users select specific repositories or define dynamic targets using repo queries to filter repositories based on specific criteria.

There are 3 modes to select one repository, many repositories, or a dynamic set of repositories.

Each one of these is available as a picker that displays a dialog, but consumers can also show the dialog from their custom anchor.
