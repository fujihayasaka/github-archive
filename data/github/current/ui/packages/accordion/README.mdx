# Accordion

The Accordion component is a vertically stacked set of interactive headings that reveal or hide associated content panels. It's useful for organizing and presenting content in a confined space.

## How to use

```tsx
import {Accordion} from '@primer/react-components'

function MyAccordion() {
  const [expandedItems, setExpandedItems] = useState<string[]>([])

  return (
    <Accordion expandedItems={expandedItems} onChange={setExpandedItems}>
      <Accordion.Item value="item1">
        <Accordion.Trigger>Item 1</Accordion.Trigger>
        <Accordion.Content>Content for Item 1</Accordion.Content>
      </Accordion.Item>
    </Accordion>
  )
}
```

## Properties

### Accordion

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `expandedItems` | `string[]` | Yes | Array of item values that are currently expanded |
| `onChange` | `(expandedItems: string[]) => void` | Yes | Callback fired when the expanded state changes |
| `className` | `string` | No | Additional CSS class names |
| `children` | `ReactNode` | Yes | Accordion.Item components |

### Accordion.Item

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `value` | `string` | Yes | Unique identifier for the accordion item |
| `className` | `string` | No | Additional CSS class names |
| `children` | `ReactNode` | Yes | Must include Accordion.Trigger and Accordion.Content components |

### Accordion.Trigger

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `id` | `string` | No | Custom ID for the trigger button |
| `className` | `string` | No | Additional CSS class names |
| `children` | `ReactNode` | Yes | Content to display in the trigger button |

### Accordion.Content

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `className` | `string` | No | Additional CSS class names |
| `children` | `ReactNode` | Yes | Content to show/hide when the trigger is activated |

## Accessibility

The Accordion component follows WAI-ARIA Accordion Pattern guidelines:

- Uses appropriate ARIA attributes (`aria-expanded`, `aria-controls`) to indicate the state and relationships between elements
- Keyboard navigation support:
  - Enter or Space: Expands/collapses the accordion section
  - Tab: Moves focus between accordion headers
  - Arrow keys: Moves focus between accordion headers
- Headers can be marked up with proper heading levels for semantic structure
- Focus management handles both mouse and keyboard interactions appropriately
