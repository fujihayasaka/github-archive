# RegexTesterDialog

{/* A precise description of your component and the use cases it covers. */}

A dialog for testing what patterns match a given regular expression

## Example

{/* An example of the most prominent use case of your component to demonstrate its capabilities. */}

Ensure the `custom_properties_regex` feature flag is enabled. You can view an example of this component by going to
the Organization settings tab and creating a Custom Property (located underneath the Repository heading on the sidebar).
Click the checkbox labeled "Match regular expression" and then press the button labeled "Test values".

Ensure the `member_privilege_rulesets` feature flag is enabled. You can view another example of this component by going
to the Organization settings tab and creating a Repository Policy (located underneath the Policies heading on the sidebar).
Click the checkbox labeled "Restrict names" and then press the button labeled "Test pattern".

## How to use

{/* An implementation example of your component. Ideally it's functional so that users can run and play with it. */}

Enter a regular expression in the textbox labeled "Pattern" and then enter a string in the textbox labeled "Test value".
Press the "Check" button and then a validation message will appear informing you whether the value matches the pattern or not.
