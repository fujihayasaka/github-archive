# CopilotAnimation

`CopilotAnimation` is an animated flat Copilot logo that can express various emotions and reactions. It's used to add polish and delight to Copilot experiences.

```tsx
<CopilotAnimation animationType="celebrate" loopAnimation size="64" />
```

## Accessibility

`CopilotAnimation` presents as a presentational component that is hidden from screen readers. It should be treated as decorative and not used alone to provide any critical information to the user.
