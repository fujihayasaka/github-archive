# `SimpleSelect`

`SimpleSelect` is a lightweight dropdown component designed to act as a `<select>` or `combobox` without filtering functionality. It supports single and multiple selection modes, as well as grouping and controlled states. `SimpleSelect` is built on top of Primer components like `ActionList`, `AnchoredOverlay`, and `Button`.

Typically, `SimpleSelect` should be used when you need a dropdown with selection capabilities but do not require advanced filtering or search functionality. For more complex use cases, consider using `SelectPanel`.

---

## Description

A lite version of `SelectPanel`, which aims to act as a `<select>` and/or `combobox` without filtering functionality.

---

## Dependencies

`SimpleSelect` uses the following Primer components internally:

- [`ActionList`](https://primer.style/react/ActionList)
- [`AnchoredOverlay`](https://primer.style/react/AnchoredOverlay)
- [`Button`](https://primer.style/react/Button)

---

## Variants

### Single Select

Allows users to select a single option from a predefined list of choices. This variant is ideal for forms or interfaces where only one selection is allowed.

```tsx
const items = [
  {label: 'Item 1', id: 'item-1', selected: true},
  {label: 'Item 2', id: 'item-2', selected: false},
]

<SimpleSelect
  items={items}
  selectionVariant="single"
  label="Select an item"
  onSelect={selectedItem => { /* Do some action */ }}
/>
```

---

### Multi Select

Allows users to select multiple options from a predefined list of choices. This variant behaves like a checkbox group, enabling users to select multiple options and either save or cancel their selections.

```tsx
const items = [
  {label: 'Item 1', id: 'item-1', selected: true},
  {label: 'Item 2', id: 'item-2', selected: true},
  {label: 'Item 3', id: 'item-3', selected: false},
]

<SimpleSelect
  items={items}
  selectionVariant="multiple"
  label="Select items"
  onSelect={selectedItem => console.log(selectedItem)}
  onSave={savedItems => console.log(savedItems)}
  onCancel={prevItems => console.log(prevItems)}
/>
```

---

### Grouped Items

Supports grouping of items within the dropdown. Each group is rendered within a separate container with `role="group"` via `ActionList`.

```tsx
const items = [
  {label: 'Item 1', id: 'item-1', selected: false, groupId: 1},
  {label: 'Item 2', id: 'item-2', selected: true, groupId: 1},
  {label: 'Item 3', id: 'item-3', selected: false, groupId: 2},
]

<SimpleSelect
  items={items}
  selectionVariant="multiple"
  label="Select items"
/>
```

---

### Custom Render Text

Allows customization of the text displayed in the button. This is useful for cases where the default text format does not meet the design requirements.

```tsx
const renderText = () => 'Custom Text'

const items = [
  {label: 'Item 1', id: 'item-1', selected: false},
  {label: 'Item 2', id: 'item-2', selected: true},
]

<SimpleSelect
  items={items}
  selectionVariant="single"
  renderText={renderText}
/>
```

---

### Controlled State

Supports a controlled state by passing the `selectable` prop. This allows external management of the selection state.

#### Single Select (Controlled)

```tsx
const items = [
  {label: 'Item 1', id: 'item-1', selected: false},
  {label: 'Item 2', id: 'item-2', selected: false},
]

const [selectedItems, setSelectedItems] = React.useState<Items[]>([])

<SimpleSelect
  items={items}
  selectionVariant="single"
  label="Select an item"
  selectable={setSelectedItems}
/>
```

#### Multi Select (Controlled)

```tsx
const items = [
  {label: 'Item 1', id: 'item-1', selected: false},
  {label: 'Item 2', id: 'item-2', selected: false},
  {label: 'Item 3', id: 'item-3', selected: false},
]

const [selectedItems, setSelectedItems] = React.useState<Items[]>([])

<SimpleSelect
  items={items}
  selectionVariant="multiple"
  label="Select items"
  selectable={setSelectedItems}
/>
```
