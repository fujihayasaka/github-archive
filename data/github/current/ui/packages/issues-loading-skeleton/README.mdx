# IssuesLoadingSkeleton
Replaces ui/packages/skeleton/LoadingSkeleton.tsx in order to prevent potential hydration errors. See https://github.slack.com/archives/CD1AK7VT3/p1736775439933599?thread_ts=1736772543.361989&cid=CD1AK7VT3.
Will be used across Issues packages.

## Example
Will replace the currently used ui/packages/skeleton/LoadingSkeleton.tsx across Issues packages in a follow-up PR.

## How to use
```
<IssuesLoadingSkeleton height={20} width={30} />
```

## Properties

<ArgTypes of={ IssuesLoadingSkeleton } />

## Options (optional)

Users can pass numeric and string values for width, height and borderRadius. The component understands "sm", "md", "lg" and "xl" values for width and height and "rounded", "pill", "elliptical" for the border radius.

## Accessibility (optional)
The SkeletonBox Primer component (https://primer.style/components/skeleton-box/react/draft) is not yet reviewed for accessibility.
