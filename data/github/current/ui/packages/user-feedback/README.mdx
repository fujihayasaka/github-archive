## How to Use

To use the `UserFeedback` component, you'll need to:

1. **Create a Ref**: Use the `useRef` hook to create a reference to the `UserFeedback` component.
2. **Trigger the Dialog**: Use the `ref` to call the `openDialog` method from any interactive element, such as a button.

### Step-by-Step Example

```tsx
import React, { useRef } from 'react';
import { UserFeedback, FeedbackRef } from './UserFeedback';
import { Button } from '@primer/react';

const FeedbackExample = () => {
  // Create a ref for the UserFeedback component
  const feedbackRef = useRef<FeedbackRef>(null);

  return (
    <>
      {/* Button to trigger the feedback dialog */}
      <Button onClick={() => feedbackRef.current?.openDialog()}>
        Feedback
      </Button>

      {/* UserFeedback component with the ref */}
      <UserFeedback ref={feedbackRef} />
    </>
  );
};

export default FeedbackExample;
