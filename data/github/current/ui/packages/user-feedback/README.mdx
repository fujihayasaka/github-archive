# UserFeedback

**REACH OUT IN #COPILOT-HYPERSPACE FOR MORE INFORMATION!**

A dialog to solicit a rating and textual feedback from users.

## How to Use

To use the `UserFeedback` component, you'll need to:

1. **Create a Ref**: Use the `useRef` hook to create a reference to the `UserFeedback` component.
2. **Define rating options**: Create an array of RatingOption objects for users to choose from.
3. **Trigger the Dialog**: Use the `ref` to call the `openDialog` method from any interactive element, such as a button.

### Step-by-Step Example

```tsx
import React, { useRef } from 'react';
import { UserFeedback, FeedbackRef } from './UserFeedback';
import { Button } from '@primer/react';

const options = [
  { name: 'Bad', value: 'BAD' as const, icon: <ThumbsdownIcon />, color: 'bad' },
  { name: 'Good', value: 'GOOD' as const, icon: <ThumbsupIcon />, color: 'good' },
];
type Rating = (typeof options)[number]['value'];

const FeedbackExample = () => {
  // Create a ref for the UserFeedback component
  const feedbackRef = useRef<FeedbackRef<Rating>>(null);
  const onSubmit = (rating: Rating, text: string) => {
    // Handle the feedback submission
  };

  return (
    <>
      {/* Button to trigger the feedback dialog */}
      <Button onClick={() => feedbackRef.current?.openDialog()}>
        Feedback
      </Button>

      {/* UserFeedback component with the ref */}
      <UserFeedback ref={feedbackRef} options={options} onSubmit={onSubmit} />
    </>
  );
};

export default FeedbackExample;
