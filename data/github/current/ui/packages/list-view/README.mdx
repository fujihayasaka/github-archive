# ListView

The ListView is a collection of items that each have:

- A primary piece of information and action,
- One or multiple secondary actions, and
- Associated metadata about the primary piece of information.

## 🤓 How to Use

Below is a classic example of a `ListView`:

```jsx
import {ActionList} from '@primer/react'
import {ListView} from '@github-ui/list-view'
import {ListViewDensityToggle} from '@github-ui/list-view/ListViewDensityToggle'
import {ListViewMetadata} from '@github-ui/list-view/ListViewMetadata'
import {ListItem} from '@github-ui/list-view/ListItem'
import {ListItemTitle} from '@github-ui/list-view/ListItemTitle'
import {ListItemTrailingBadge} from '@github-ui/list-view/ListItemTrailingBadge'
import {ListItemLeadingContent} from '@github-ui/list-view/ListItemLeadingContent'
import {ListItemLeadingVisual} from '@github-ui/list-view/ListItemLeadingVisual'
import {ListItemMainContent} from '@github-ui/list-view/ListItemMainContent'
import {ListItemDescription} from '@github-ui/list-view/ListItemDescription'
import {ListItemActionBar} from '@github-ui/list-view/ListItemActionBar'

const FeatureListView = () => {
  return (
    <ListView title="List of issues" metadata={<ListViewMetadata densityToggle={<ListViewDensityToggle />} />}>
      <ListItem
        title={
          <ListItemTitle
            value="Sample issue #1"
            href="#"
            onClick={noop}
            trailingBadges={[<ListItemTrailingBadge key={0} title="trailing badge" />]}
          />
        }
        secondaryActions={
          <ListItemActionBar
            label="Sample secondary actions bar"
            staticMenuActions={[
              {
                key: 'mark-as',
                render: () => <ActionList.Item>Mark as</ActionList.Item>,
              },
            ]}
          />
        }
      >
        <ListItemLeadingContent>
          <ListItemLeadingVisual />
        </ListItemLeadingContent>

        <ListItemMainContent>
          <ListItemDescription>
            {"Sample issue #1's description of long text here in the ListItemDescription"}
          </ListItemDescription>
        </ListItemMainContent>
      </ListItem>
    </ListView>
  )
}
```

Find out more about the available components and their attributes in the [Components page](?path=/docs/recipes-listview-documentation-components--docs)

## ♿️ Accessibility

ListView is an interactive list. Interactive lists are less common on the web, and are typically found on a desktop/laptop Operating System instead. Read more about the [accessibility of ListView in the overview](?path=/docs/recipes-listview-documentation-accessibility--overview)
