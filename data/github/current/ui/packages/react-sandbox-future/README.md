## What is the NEW React Sandbox?

This sandbox is a playground for building the [new React Data Fetching platform](https://github.com/github/react-platform/issues/17) based on `queryRoute`.

It replaces the OLD sandbox which was built to support the old data-fetching platform based on `jsonRoute`/`relayRoute` which we are in the process of deprecating.

See <https://github.com/github/react-platform/issues/161>

## Under Construction 🚧

**The `queryRoute` based platform is under construction and is not ready for general use.** In the meantime, we'd love your feedback on the design. You read about it in the [EDR: A Paved Path For React Data](https://gh.io/edr-react-data) document. And you can get in touch with us in [#react](https://github-grid.enterprise.slack.com/archives/CD1AK7VT3) on Slack.
