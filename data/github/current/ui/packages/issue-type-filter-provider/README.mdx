# IssueTypeFilterProvider

The `IssueTypeFilterProvider` should be used with the `Filter` component. It is responsible for returning issue type suggestions when querying issues or PRs.

## How to use

```tsx
import {AssigneeFilterProvider, StatusFilterProvider} from '@github-ui/filter/providers'
import { IssueTypeFilterProvider } from './IssueTypeFilterProvider'



const filterProviders = useMemo(() => ([
  new IssueTypeFilterProvider(),
]), [])

<Filter providers={filterProviders} />

```
